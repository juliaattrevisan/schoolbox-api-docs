_Rules_

-   CSS ordered alphabetically
-   One component per file
-   Parent styles, followed by elements, followed by modifiers
-   No more than 3 levels of nesting

### Prefixes

_Table of class prefiexes that identify new styles_

-   `c-*` : Component
-   `f-*` : An override linked to the old styles.
-   `l-*` : Layout
-   `u-*` : Utility
-   `t-*` : Typography
-   `wc-*` : Web Component
