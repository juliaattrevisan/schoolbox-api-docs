# Roundess

`www/static/css/core/layout/_roundness.scss`

Global values to control the roundness of components within our platform. They're currently broken down into three categories. Where appropriate all new components should include these.
In future there may be potential to add these to the custom skin config so schools can customise.

| CSS Custom Property  | Value | Description                                                      |
| -------------------- | ----- | ---------------------------------------------------------------- |
| `--roundness-images` | `0`   | To round images in some contexts, for example within small cards |
| `--roundness-cards`  | `0`   | To round cards                                                   |
| `--roundness-inputs` | `0`   | To round text inputs                                             |
