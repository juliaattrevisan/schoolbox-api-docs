# Colours

These are the colours currently avaiable as CSS custom properties. As we continue to migrate from Foundation/SASS vars to CSS custom properties, we will be adding more colours to this list.

## User Configurable

The following colours are configurable by schools via the admin system. The following colours currently match those used in the demo data, visible at: https://demo.schoolbox.com.au/login/
