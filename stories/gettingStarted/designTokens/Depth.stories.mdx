# Depth _(z-index)_

In our process, we have the capability to perform operations like adding or subtracting 1. However, if the outcome goes below -3, it signals that introducing another base number might be necessary for better management.

_Draft_

| CSS Custom Property        | Value | Description                                                              | Example                                                   |
