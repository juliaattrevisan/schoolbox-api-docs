# Proposed Colours

| Property             | Description                                                      | CSS Custom Property          | Previously                |
| -------------------- | ---------------------------------------------------------------- | ---------------------------- | ------------------------- |
| Body Background      | The background                                                   | `--color-body-background`    | `--body-background`       |
| Primary Foreground   |                                                                  | `--color-foreground-primary` |                           |
| Secondary Foreground | A darker shade of Primary Foreground                             | `--color-foreground-primary` |                           |
| Primary Text         | For the majority of text                                         | `--color-text-primary`       |                           |
| Secondary Text       | A lighter shade of Primary text, for text like hints             | `--color-text-secondary`     |                           |
| Form Elements        | Used in form elements like checkboxes, radio buttons and toggles | `--color-form-elements`      | `--form-border-colour`    |
| Focus                | To help highlight interactive elements when focus is assigned    | `--color-focus`              |                           |
| Alert                |                                                                  | `--color-alert`              | `$alert-color`            |
| Success              |                                                                  | `--color-success`            | `$alert-success`          |
| Warning              |                                                                  | `--color-warning`            | `$alert-warning`          |
| Button               |                                                                  | `--color-buttons`            | `--content-ui-foreground` |
| Button               |                                                                  | `--color-buttons`            | `--content-ui-hover`      |
