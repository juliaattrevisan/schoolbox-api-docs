# Design Tokens

Design tokens are consistent, reusable, and well-defined variables that capture the fundamental elements of a design system, such as colours, typography, spacing, and more.
They serve as the atomic units of a design language, allowing designers and developers to maintain design consistency across different platforms and applications.
By abstracting design decisions into tokens, design systems become more flexible, adaptable, and scalable, promoting cohesive branding and efficient development workflows.

## Spacing

In order to maintain consistency across the design system, we use a consistent set of spacing values.
These values are based on the [8-point grid system](https://spec.fm/specifics/8-pt-grid) and are defined in `rem` units.
As the default root text size is `16px`, `1rem` is equivalent to `16px`.
These values are to be used for all spacing needs, including `margin`, `padding`, and `gap`.

```
--whitespace-xs: 0.25rem;
--whitespace-s: 0.5rem;
--whitespace-m: 1rem;
--whitespace-l: 1.5rem;
--whitespace-xl: 2rem;
```
