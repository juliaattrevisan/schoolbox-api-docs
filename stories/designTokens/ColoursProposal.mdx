# Colours

![draft](/draft.png)

-   See `stories/assets/styles/styles.scss`
-   Figma: https://www.figma.com/design/kcebwjgNDzqyTtXZzgQNMO/UI-Kit?node-id=8-4

| CSS Custom Property            | Previously                | Description                                                               |
| ------------------------------ | ------------------------- | ------------------------------------------------------------------------- |
| `--color-body-background`      | `--body-background`       | The background colour                                                     |
| `--color-foreground-primary`   |                           | The primary foreground colour                                             |
| `--color-foreground-secondary` |                           | The secondary foreground colour, ideally a subtle contrast to the primary |
| `--color-text-primary`         |                           | The primary text colour, for the majority of text                         |
| `--color-text-secondary`       |                           | Ideally slightly lighter than the primary                                 |
| `--sbx-color-accent`           | `--form-border-colour`    | Used in form elements like checkboxes, radio buttons and toggles          |
| `--sbx-color-accent`           |                           | To highlight a form element when focus is assigned                        |
| `--color-alert`                | `$alert-color`            | To highlight a destructive action or warn of an unexpected event          |
| `--color-success`              | `$alert-success`          | To highlight a primary action or a successful event                       |
| `--color-warning`              | `$alert-warning`          |                                                                           |
| `--color-buttons`              | `--content-ui-foreground` | The primary colour for all buttons                                        |
| `--color-buttons-hover`        | `--content-ui-hover`      | The hover colour for all buttons                                          |
| `--color-buttons-text`         | `--content-ui-hover`      | Text colour of a primary button                                           |
