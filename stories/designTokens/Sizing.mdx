# Sizing

- Defined in: `www/static/css/core/designTokens/_sbx-sizes.scss`.
- Should always be used when defining `margin`, `padding`, and `gap`.
- These values are based on the [8-point grid system](https://spec.fm/specifics/8-pt-grid) and are defined in `rem` units.
- As the default root text size is `16px`, `1rem` is equivalent to `16px`.

| CSS Custom Property | Value     |
| ------------------- | --------- |
| `--sbx-size-xxs`    | `0.25rem` |
| `--sbx-size-xs`     | `0.5rem`  |
| `--sbx-size-s`      | `0.75rem` |
| `--sbx-size-m`      | `1rem`    |
| `--sbx-size-l`      | `1.5rem`  |
| `--sbx-size-xl`     | `2rem`    |
| `--sbx-size-xxl`    | `3rem`    |
