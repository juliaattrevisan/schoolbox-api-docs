# Depth _(z-index)_

- Created in: `www/static/css/core/base/_depth.scss`
- To globally manage the stacking order of elements, we have created the below CSS custom properties.
- All `z-index` values should be derived from these. Using `calc()`, these values can be added or subtracted to.
- However, if more than `3` additions or subtractions are required it signals that introducing another base number may be necessary for better management.

## Properties

| CSS Custom Property             | Value | Description                                                                                                |
| ------------------------------- | ----- | ---------------------------------------------------------------------------------------------------------- |
| `--sbx-depth-default`           | `1`   | The default depth level when `z-index` is required.                                                        |
| `--sbx-depth-ui-sticky `        | `10`  | Elements like `position: sticky` table headers etc.                                                        |
| `--sbx-depth-ui-overlay `       | `20`  | Elements like video player ui, image gallery ui                                                            |
| `--sbx-depth-menu`              | `30`  | Core menu, ensuring when unpinned it sits above                                                            |
| `--sbx-depth-pop-over`          | `40`  | Small "pop over" elements like the menus within `sbx-pop-out` or full calendar pop over                    |
| `--sbx-depth-modal`             | `50`  | Modal dialogs, typically taking up the full screen with a background that covers the entire browser window |
| `--sbx-depth-modal-ui-overlay ` | `60`  | Elements like CKEditor menus when they are within modals                                                   |
| `--sbx-depth-toast`             | `70`  | Toast notifications                                                                                        |
| `--sbx-depth-intro`             | `80`  | Intro tour, which highlights various elements                                                              |
| `--sbx-depth-fullscreen`        | `90`  | Full screen overlays, ensuring it appears over everything                                                  |
