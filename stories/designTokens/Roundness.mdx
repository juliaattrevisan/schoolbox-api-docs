# Roundess

`www/static/css/core/layout/_roundness.scss`

Global values to control the roundness of components within our platform. Where appropriate all new components should include these.
In future there may be potential to add these to the custom skin config so schools can customise.

| CSS Custom Property         | Description                                                      |
| --------------------------- | ---------------------------------------------------------------- |
| `--roundness-islands`       | Islands, which are the main content areas                        |
| `--roundness-images`        | To round images in some contexts, for example within small cards |
| `--roundness-cards`         | To round cards                                                   |
| `--roundness-form-elements` | To round form elements                                           |
| `--roundness-buttons`       | To round buttons                                                 |
