# Spacing

`www/static/css/core/layout/_spacing.scss`

In order to maintain consistency across the design system, we use a consistent set of spacing values.
These values are based on the [8-point grid system](https://spec.fm/specifics/8-pt-grid) and are defined in `rem` units.
As the default root text size is `16px`, `1rem` is equivalent to `16px`.
These values are to be used for all spacing needs, including `margin`, `padding`, and `gap`.

| CSS Custom Property | Value     | Description         |
| ------------------- | --------- | ------------------- |
| `--spacing-xs`      | `0.25rem` | Extra Small Spacing |
| `--spacing-xs`      | `0.5rem`  | Small Spacing       |
| `--spacing-m`       | `1rem`    | Medium Spacing      |
| `--spacing-l`       | `1.5rem`  | Large Spacing       |
| `--spacing-xl`      | `2rem`    | Extra Large Spacing |
