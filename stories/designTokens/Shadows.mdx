# Shadows

## Configurable

- Defined in: `www/static/css/core/config/_sbx-container-corner-radius.scss`.
- This property can be customised via Admin > Design > Settings - Skin Config.

| CSS Custom Property                  | Initial Value            | Description                                                                                                                                          |
| ------------------------------------ | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--sbx-config-container-drop-shadow` | `var(--sbx-shadow-none)` | Element on page background that typically has the `--sbx-color-foreground-primary` background color, such as islands, empty states, components, etc. |
