# Colours

![advanced-ui](/advanced-ui.png)

- See `www/static/css/core/designTokens/_sbx-colors.scss`
- Figma: https://www.figma.com/design/kcebwjgNDzqyTtXZzgQNMO/UI-Kit?node-id=8-4

| CSS Custom Property                  | Previously             | Description                                                                                                                                         |
| ------------------------------------ | ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--sbx-config-color-body-background` | `--body-background`    | The background color                                                                                                                                |
| `--sbx-color-foreground-primary`     |                        | The primary foreground color                                                                                                                        |
| `--sbx-color-foreground-secondary`   |                        | The secondary foreground color, ideally a subtle contrast to the primary                                                                            |
| `--sbx-color-text-primary`           |                        | The primary text color, for the majority of text                                                                                                    |
| `--sbx-color-text-secondary`         |                        | Ideally slightly lighter than the primary                                                                                                           |
| `--sbx-color-alert`                  | `$alert-color`         | To highlight a destructive action or warn of an unexpected event                                                                                    |
| `--sbx-color-success`                | `$alert-success`       | To highlight a successful event                                                                                                                     |
| `--sbx-color-warning`                |                        | To highlight a warning                                                                                                                              |
| `--sbx-color-highlight`              |                        | To highlight a text selection                                                                                                                       |
| `--sbx-config-color-accent`          | `--form-border-colour` | Use in form elements like checkboxes, radio buttons, toggles and, the primary color for all buttons. Most commonly suggests an interactive element. |
| `--sbx-config-color-accent-text`     |                        | Use when the text is on an element with the accent background color.                                                                                |
