# Actions Dropdown

To toggle the display of further navigation or control actions.

-   It will display whatever is assigned to it via: `content-id="dropdown-1"`
-   An alternative icon can be passed in via the single slot using: `<div slot="icon"><svg /></div>`
-   To add text to the button, use `button-text="My Buton Text`

**Please note:**

-   There are currently some style variations when comparing Storybook/Schoolbox. This is due to some complications so Storybook's Webpack is not yet set up exactly as our Schoolbox Webpack is. As such styles will vary slightly, so be sure to also review in Schoolbox.
-   that only the dropdown button is currently contained within the component. The dropdown content is not.
-   The central div `#container` is currently used to determine the position of the dropdown content, so the component must be contained wiithin this container

```
<sbx-actions-dropdown content-id="dropdown-1" button-text="Modify Participation">
    <div slot="icon">
        <svg />
    </div>
</sbx-actions-dropdown>
<ul id="dropdown-1" class="f-dropdown" data-dropdown-content="">
    <li class="separator">Manage</li>
    <li><a>Course Markbook</a></li>
    <li><a>Delete</a></li>
</ul>
```
