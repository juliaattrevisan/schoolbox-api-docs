# Data Table

`<data-table>` is a Vue component that renders a table of data. It uses the Vue package: `v-tables-3-select-rows`.

The table can be filtered, sorted, and paginated.

<Controls />

## `columnsConfig`

There's currently 3 types of columns that can be displayed.

### Basic

To display a basic column, pass through the following:

```
{
    key: "StaffDepartment", // The key of the data to display
    heading: "Department", // The heading of the column
    class: "hide-for-medium-down", // The class to apply to the column, in this case to hide the column on mobile
    isHidden: false, // to hide a column, typically used to add extra search data to the table
},
```

### Image

An image can be displayed in a column by passing through the following:

```
{
    key: "portrait_url",
    heading: "Image",
    class: "portrait-td",
    isSortable: false, // to prevent the column from being sortable
    template: {
        component: "image", // to target the image template
        componentData: {
            src: "portrait_url", // the src of the img to display
            href: "profile_url", // if specified, the image will be wrapped in an anchor tag
            title: "View profile", // the title of the anchor tag
            alt: "Portrait photo of user", // the alt of the img
            imgClass: "img--rounded" // to allow any custom styling of the image
        },
    },
},
```

### Link

A link can be displayed in a column by passing through the following:

```
{
    key: "StaffOccupEmail",
    heading: "Email",
    template: {
        component: "link", // to target the link template
        componentData: {
            text: "StaffOccupEmail", // the text to display
            href: "StaffOccupEmail", // the href of the link
            prependHref: "mailto:", // if specified, the href will be prepended with this
            title: "Email user", // the title of the link
            hasNoWrap: true, // to prevent the text from wrapping
        },
    },
},
```
