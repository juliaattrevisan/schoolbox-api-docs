# Cards

### Modern styling rework of our card layouts, utilising flex to do a lot of the heavy lifting

The standard implementation on a larger card like a news article consists of three parts

-   A 'main' section, which for a lot of slimline card implementations is literally all you'd need. The
    main section houses stuff like thumbnail images, a title, a subtitle/meta component, action buttons...
-   A 'content' section, which is just to house whatever content you might want to display. Let's say
    you had an \<article\> within a news card for example - put it here. All it does is add padding.
-   An 'actions' section, which can sit at the bottom and have links/actions displayed within it

The current logic here is flexible enough to handle a most standard card uses of cards, but it currently
doesn't have any of the logic required to handle the display of large cards (the last row on the cards
tab in the pantry, for example) and some of the really unique cards we have across the platform. The majority
should work just fine though.

As this is also flex based, we can leverage flex modifying classes like `l-flex--center` or `l-gap` without a problem
