# Filters Dropdown

To toggle the display of a group of filters

-   It will display whatever is assigned to it via: `content-id="dropdown-1"`
-   To add text to the button, use `button-text="Category`
-   It can be disabled via: `is-disabled`

**Note that only the dropdown button is currently contained within the component. The dropdown content is not.**

**Also, the central div `#container` is currently used to determine the position of the dropdown content.**
