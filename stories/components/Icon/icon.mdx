# Icon

To show an icon

## Properties

| Property | Type     | Description                                                                                                       | Default                        | Options                                                                   |
| -------- | -------- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------ | ------------------------------------------------------------------------- |
| `name`   | `string` | The name of the icon, as specified at [Design Token/Icons](?path=/docs/getting-started-design-tokens-icons--docs) | `""`                           | Any string name linked to an icon                                         |
| `size`   | `string` | The size of the icon                                                                                              | `m`                            | `xs`, `s`, `m`, `l`, `xl`, or any other approriate size value like `36px` |
| `color`  | `string` | The color of the icon.                                                                                            | `var(--content-ui-foreground)` | Can accept any valid CSS colour value, including custom properties.       |
