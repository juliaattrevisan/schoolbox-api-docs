# Icon

To show an icon

## Properties

| Property | Type     | Description                                                  | Default                      | Options                                                             |
| -------- | -------- | ------------------------------------------------------------ | ---------------------------- | ------------------------------------------------------------------- |
| `name`   | `string` | The name of the icon, as specified at [Design Token/Icons]() | ""                           | Any string name linked to an icon                                   |
| `size`   | `string` | The size of the icon                                         | m                            | xs, s, m, l, xl, (x)rem where x can be any numeric value            |
| `color`  | `string` | The color of the icon.                                       | var(--content-ui-foreground) | Can accept any valid CSS colour value, including custom properties. |
