### Basic card

```js
<Card title="Basic card" meta="Meta information" />
```

### Card with content

In order for a card to have content- it needs to be contained in an `.information-list` (this will be made a component soon)

```js
<div class="information-list">
  <Card title="Card with content" meta="Meta information">
    <p>Some content</p>
  </Card>
</div>
```
