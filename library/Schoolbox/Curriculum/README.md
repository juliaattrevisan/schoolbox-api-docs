# Schoolbox Curriculum Mapping

To get started, be logged in as a superuser and navigate to http://192.168.36.10/curriculum/import - 
from there:

* select and use the "Australian Curriculum" source, as it's the only one that has been installed
* select whichever level and area you want to use
* you will receive a preview of the curriculum sections that will be imported. Click "Save Curriculum"

You'll be sent to the curriculum browser, with the curriculum you just created open. From here you
can:

* browse each curriculum's sections
* add, edit and delete subsections
* add an entirely new curriculum
