## pastoral_report_dashboard

| column | description |
|--- | --- |
| id | Unique row identifier |
| user_id | The ID of the user whose dashboard the report should appear on |
| report_id | The ID of the pastoral care report the user wants to show on their dashboard |
| created_at | The date/time the time the pastoral report was added |
| updated_at | Redunant field since you can't update anything meaningful here |
| deleted_at | The date/time the time the pastoral report was removed |
