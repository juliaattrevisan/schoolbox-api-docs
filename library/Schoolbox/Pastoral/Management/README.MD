## TLDR

This is intended to be the launchpad for administrative tasks within the pastoral care system. Due to the sensitive
nature of pastoral care issues- and the (albeit slightly moot) distinction that superusers are given no special
access to pastoral care, a divide was intentionally setup between the normal admin pages, and the pastoral admin
pages.

Currently this is limited to pastoral group administration, however in the long term, the pastoral importer should also 
be moved here from the admin page, along with some way to view thepastoral care aud t trails.
