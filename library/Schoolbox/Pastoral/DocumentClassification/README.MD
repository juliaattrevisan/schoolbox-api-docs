## TLDR

This is a concept that is exclusive to Synergetic. Records in Synergetic have a 'document classification' which
determines its accessibility by users. We maintain a table of document classifications inside Schoolbox, along
with their external Synergetic code.

We then allow superusers to link a document classification to each of our 'Pastoral Types'. Then when a pastoral record 
is written back to Synergetic- this document classification is saved along with the record in Synergetic.

Document classifications have has no effect on the use of Schoolbox.
