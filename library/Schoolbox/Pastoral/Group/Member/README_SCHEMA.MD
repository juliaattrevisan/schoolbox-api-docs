## pastoral_group_member

| column | description |
|--- | --- |
| id | Unique row identifier |
| user_id | The ID of the user that is a member of the group |
| group_id | The ID of the group this user belongs to |
| author_id | The ID of the user that added the person to the group |
| created_at | The date/time the time the pastoral group was created |
| deleted_at | The date/time the time the pastoral group was deleted |
