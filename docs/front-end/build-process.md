# Build Process

All frontend packages are installed using NPM.

* `npm install` to install packages defined in `package.json`
* `npm run build` to build Schoolbox's JavaScript and CSS
* `npm run watch` to set up a file watcher to watch for changes to Schoolbox's
  JavaScript and CSS, and rebuild when they change

## Package Managers

[Composer](https://getcomposer.org/): PHP package management.

[NPM](https://www.npmjs.com/): Currently being used for frontend package management, and to add build tools.
