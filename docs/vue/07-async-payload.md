# 7. Asynchronous Payload

Sometimes you don't want to load data synchronously and you're after something similar to jQuery's `$.ajax` method. The Vue equivalent is `axios` and it functions in a very similar way.

## 7.1 Set up asynchronous payload endpoint in Aura

Instead of rendering a twig template, we need to render a json_encoded data structure. In our Greenhouse controller, we need to provide another endpoint for the actual data, rather than the Vue Container.

In `Module.php`,

```php
$this->register('GET', '/payload', 'getPayload', $isAdministrator);
```

In `Controller.php`,

```php
public function getPayload(): void
{
    $users = $this->userMapper->findAll();

    $data = [];

    foreach ($users as $user) {
        $data[] = [
            'fullname' => $user->getFullname(),
            'firstname' => $user->getFirstname(),
            'lastname' => $user->getLastname(),
            'role' => $user->getRole()->getName(),

            /* This could be generated by router(), for example
             */
            'route' => "/search/user/{$user->getId()}"
        ];
    }

    $this->getResponse()->content->set($this->buildJsonOutput($data));
}


public function getContainer(): void
{
    $this->getResponse()->content->set($this->buildHtmlOutput('@greenhouse/container.twig', []));
}
```

And finally in `container.twig` we don't need to pass a payload data structure anymore; we'll be getting its contents asynchronously:

```html
<user-list></user-list>
```

## 7.2 Set up axios

We need to import the `axios` library at the top of `user-list.vue`,

```js
import axios from 'axios';
```

Then in `mounted()` (the Vue equivalent of window.onload), we need to set up a few things.

* A var to indicate that we're currently loading data `loading`
* A var to store the data we'll load `allUsers`

> The `data` node returns an object literal containing vars that you want to access throughout your view component, like local vars.

```js
data() {
    return {

        /* True, when data is currently loading; used to show skeleton
         */
        loading: true,

        /* A list of all the users
         */
        allUsers: []
    }
},
```

In `mounted`, when Vue has finished fooling around getting itself started:

* Remember a reference to `this` which you'll need inside callbacks
* Initiate the async request

```js
mounted: function () {
    let self = this;

    /* Show skeleton
     */
    this.loading = true;

    /* Fetch payload asynchronously
     */
    let request = {
        url: '/greenhouse/payload',
        method: 'get',
        responseType: 'json'
    }

    axios.request(request)
        .then(function (response) {

            /* Load into vue component
             */
            self.allUsers = response.data;
        })
        .catch(error => {
            if (error.response) {
                self.loading = false;
            }
        })
        .then(function () {

            /* Hide skeleton
             */
            self.loading = false;
        });
}
```

In `user-list.vue`,

* Show an element to tell people we're loading things

```html
<template v-if="this.loading">
    <div>
        <h2>Loading data, wait</h2>
    </div>
</template>
<template v-else>
    <ul class="information-list">
        <li v-for="user in this.allUsers">
            <user :fullname="user.fullname"
                  :firstname="user.firstname"
                  :lastname="user.lastname"
                  :role="user.role"
                  :route="user.route"
                  :nameLength="nameLength(user.fullname)">
            </user>
        </li>
    </ul>
</template>
```

If you compile and reload the screen, you'll briefly see a `Loading` message which will suddenly go away in place of a familiar output. You can use the Vue devtool to see the contents of your payload too.

> Don't forget to dress up the Loading screen with skeletons or other ui fancyness.

> You can also handle errors inside the `axios.request` call, just like you would with the jQuery equivalents.
