# Notification Subsystem

The Schoolbox notification subsystem is used to schedule, route and deliver
notifications about events which have occurred within Schoolbox to users which
have subscribed to those events.

The notification subsystem is far too complicated to document in detail here
(and documentation already exists in
[docs/notifications/README.md](../../notifications/README.md)).

Nonetheless, documentation is still provided on the adapter
[here](../adapters/notification-subsystem.md).
