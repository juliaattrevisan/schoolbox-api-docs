# SIS Database

The Student Information System (a.ka. SIS) database is used to store data which
is traditionally supplied by a school's SIS.

This data will generally be entered in via that SIS, and not by Schoolbox.

## Data

SIS databases contain the following data consumed by Schoolbox:
- Lists of users (e.g. staff members, students, guardians of students)
- Relations between users (e.g. guardianship)
- Classes, their teachers and enrolments
- Timetables
