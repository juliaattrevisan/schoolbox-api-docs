# Logging Time

## Software
Most of the developers use [Toggl](https://toggl.com) to track what they have spent time on.

## NetSuite
All your time spent on work that is billable to a client must be logged on [NetSuite](https://system.na2.netsuite.com/).
(Each Jira ticket that is billable will contain a reference to the NetSuite job to log time on.)

There is no need to log any time spent on anything that is not billable.
