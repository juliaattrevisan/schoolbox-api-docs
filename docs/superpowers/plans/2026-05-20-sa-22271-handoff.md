## Implemented Scope

SA-22271 replaces the grades page client-side instructor/student mark toggle with a server-side view mode. Staff can switch between:

- `staff`
- `student`
- `parent`

The selected mode is passed as `viewMode=staff|student|parent` and is preserved through the grades summary/detail pages, term selector, subject selector, and filter-panel route.

The effective viewer now controls server-side behaviour for:

- assessment/activity visibility.
- feedback visibility.
- instructor mark input vs learner-facing mark display.
- weighted averages, overall grades, grade averages, and graph data.
- language in the view switcher.
- the grades customisations link from the summary page.

## Behaviour Notes

- Invalid or missing `viewMode` values default to staff mode.
- Staff mode uses the logged-in staff user as the effective viewer and allows instructor marks when that user has a staff role.
- Student mode uses the viewed student as the effective viewer and hides instructor-only mark controls.
- Parent mode attempts to load an actual parent for the viewed student. If no parent is available, it uses a parent-role fallback user with the viewed student attached as a child so relationship checks still work.
- The customisations link is prepared from the grades summary context and keeps the selected view mode preserved where relevant.
