FOREWORD

Which option should you go for? It entirely depends on the unique use case of what you require, but as a rough guide...

If you need to align content across two axes, use grid
If you only need to align content across a single axis, use flex

Before you resort to using legacy (twelve column) grid styles, as yourself - is it absolutely necessary for this to use a twelve column grid?
