Button Specimens

This specimen page shows you how all the types of button are built and how they compare to each other.

There are multiple button implementations; some are used on their own, some within other containing elements etc. You can check their dimensions and construction here, and their interaction with each other.

The first column contains a control button, which is the common button element living on its own. The second column contains other button constructs which are compared against the control button to test implementation and dimensioning.

  1. Each button is always at least 48px (3rem) tall
  2. Adjacent buttons are always separated by a 1px (0.0625rem) margin
