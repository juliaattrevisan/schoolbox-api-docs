The show due work picker searches for a form input with name="folderId"; it fetches assessments from a folder with ID that matches that input's value.

Syncable dates

When two date or datetime inputs that are synced, the start value cannot be after the end value. (If the end is set before the start, the start will automatically update to the end value, and vice versa.)
