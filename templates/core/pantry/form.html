In Most Cases, Single Column Works Best

The <fieldset/> has been given the same styles as .row. The implication of this is that you should put .columns directly into fieldsets (after the <fieldset/>, if you're using one.)

    Dates and Times

    When invoking $.timepicker(), use the appendTo option to attach to the parent of the <label/> which should have a class of .timepick. That way, the picker dropdown can adopt a width to match the input, which will be 100% of its container.
