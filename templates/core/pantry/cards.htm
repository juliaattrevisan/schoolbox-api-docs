  • Things to Note
    • .information-list > li does not require .row on its list items.
    • .card class extends .column so you don't need to wrap it
    • List-item actions are contained by <nav/>. If you do include row actions, you need to indicate this on the <li/> with .actions-{size}-{action-count} . These stack in the same way as column sizings, so you can have different numbers of actions on different viewports.
