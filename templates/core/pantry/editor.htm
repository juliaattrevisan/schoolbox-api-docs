Default Editor

This is the default usage of our ckeditor. There are a few special plugins that we made like Resource and ResourceLink which allow users to open the resource modal to select files already within Schoolbox.

Tokens can also be used. Typing [ in the editor will bring up the default list of tokens available. If you wish to use other tokens, pass in tokenList: as an array.

By default the Word count at the bottom is off, so it can be shown by passing showWordCount: true to the editor.

Comment Editor

This is the comment usage of our ckeditor, a simplified version of the default editor. It's designed for places like comments and forum posts.

Simple Editor

This is the simple usage of our ckeditor. As there's no resource embedding it's designed for places like email usage and blurbs in news.

Markdown Editor

This is the markdown usage of our ckeditor, this changes the output from HTML to Markdown and is designed for places that need light formatting without the entire content becoming HTML.

Markdown can be enabled for any of the above toolbars, however some features are unsupported and will not be shown

Inline Editor

This is the inline usage of our ckeditor.

Inline editor comes with a floating toolbar that becomes visible when the editor is focused (for example, by clicking it). Unlike classic editor, inline editor does not render instead of the given element, it simply makes it editable. As a consequence the styles of the edited content will be exactly the same before and after the editor is created.

A common scenario for using inline editor is offering users the possibility to edit content in its real location on a web page instead of doing it in a separate administration section.

Schoolbox Link Modal

This plugin allows you to arbitrarily spawn a Mr Matt Modal, generate a link to a resource, then postprocess the url to that resource in whatever way you need.
