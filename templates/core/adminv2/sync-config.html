External Database Sync Configuration

The rules defined here will dictate how users will be synchronised. In order for a rule to match, ALL conditions of the rule must evaluate to true for the given user, otherwise the conditions of that rule will not be applied. This can be used for making distinctions between subgroups, such as differentiating on both Role and Campus simultaneously.

The order of the rules below is the order they would be applied to a user; this order is ascending order of precedence (defined as the number of conditions, and then rule order).
