CSV template

Download

  1. Download the template file using the above button
  2. Edit the file in Microsoft Excel or equivalent editor
  3. Save the file
  4. Upload by clicking 'choose file' under "Upload new calendar entries"

Microsoft Outlook ICS

  1. In Outlook, Click Calendar in the bottom left
  2. Go to File, Save As
  3. Choose iCalendar format (*.ics)
  4. Click More Options
  5. Change Detail from Availability Only to Full Details
  6. Click OK
  7. Save it
  8. Upload by clicking 'choose file' under "Upload new calendar entries"
