WebDAV Configuration

The rules defined here will dictate how users' WebDAV configurations will be determined. In order for a rule to match, ALL conditions of the rule must evaluate to true for the given user, otherwise the conditions of that rule will not be applied. This can be used for making distinctions between subgroups, such as differentiating on both Role and Campus simultaneously.

If multiple rules match a user, each will be applied in ascending order of precedence (defined as the number of conditions, and then rule order). In the case of paths, values will be appended; in the case of URI, username and password, values will be overwritten.
