Creating Rubric Results
Edit the rubric resultsets here: these are the pre-populated default values that will appear on every rubric.
Note that once results have been created, they cannot be removed; they can be renamed, but ensure that if you do that you rename them to something semantically equivalent, since it will affect all marks already given.
Each set should be a discrete list of items of a single measurement; for example, 'Very Good' and 'Yes' should not be in the same set.
The first element is always valued zero, and sets must contain at least two elements.
Type into empty fields to add result elements; if you wish to remove a newly created element, just leave it blank.
New sets cannot be deleted once created.
