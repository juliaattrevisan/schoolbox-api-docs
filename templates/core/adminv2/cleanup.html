Remove Deleted Files

If a user has deleted a file or link this will clean up the soft deleted remnants. This should be completed yearly to keep disk usage down.

Remove Files

Remove Expired News

This function will delete any news that has expired and is no longer available. You should only run this if your news system is running slow. We do not recommend doing this as it will remove all news from the archives.

Remove Archives

Clean filesystem of stale files

This function will scan the filesystem for files that are no longer in the database. This can occur due to errors in processing or cleanup. This should be completed once a year to minimise disk wastage.

Clean Filesystem

Clean Log Files

This will delete all content from the log tables and help speed up the system. The log tables include the login log, submission box, homepage access and CMS log. This should be completed once a year.

Clean Log Files

Clean Image Cache

If you are having issues with image thumbnails or you would like to free up some diskspace. Note his will increase server load and page load times while images are recreated.

Clean Image Cache

Clean Stream Cache

The stream cache is used to store items downloaded from remote systems and zip archives to be downloaded. This can be safely deleted yearly or more frequently as all data is replaceable. This will increase page load times while the cache items are refetched.

Clean Data Cache
