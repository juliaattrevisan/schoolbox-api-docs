Submission Grades and Groupings

Guide

Creating Grades
Type into empty fields to create a new grade grouping, or a new grade level for an existing grouping.
Once grades or groupings have been created, they cannot be removed; they can be renamed, but ensure that if you do that you rename them to something semantically equivalent, since it will affect all marks already given.

Glossary

Lower Bound
This value is used for the purpose of displaying a grade average for a student or assessment. The caption with the highest lower bound above the average grade will be displayed.
Normalised Grade
The value (out of 100) that will be used for grade average calculations for an assessment that you give this grade.
This value should be greater than (not equal to) the lower bound, and less than (not equal to) the next highest lower bound.
