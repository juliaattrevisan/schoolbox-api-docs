Submission Grades and Groupings

  • Edit the grades and groupings for grades here. These options will be available to use on all submissions.
  • Note that once grades or groupings have been created, they cannot be removed; they can be renamed, but ensure that if you do that you rename them to something semantically equivalent, since it will affect all marks already given.
  • Type into empty fields to add result elements; if you wish to remove a newly created element, just leave it blank.
