Criteria

Criteria are used as rows in a rubric. You must first add criteria before you can build a rubric.

If you want to delete a criterion that has already been used on an assessment, you need to first remove it from the assessment, then you can delete it.

If you remove all the criteria from a group, the group will automatically be deleted.

See example rubric criteria

Each criterion should be a word or short sentence that describes what is being assessed, organised into logical groupings.
