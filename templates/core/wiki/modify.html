Wikis allow you to create a document and track all changes to the document. Once created all users with read access to the page can edit the document.

Creating New Stub Pages

To create a new wiki document you may use the link function to automatically create new pages.

  1. Highlight the word you wish to link
  2. Click the link button in the top
  3. Leave the Link URL empty
  4. Type in the Title field the name of the new document

The system will automatically link this document to the new stub document. Links will remain in red until the content has been updated in the new document.
